# =============================================================================
# Wellira — robots.txt
# =============================================================================
# O site é aberto aos buscadores. Este arquivo existe por um motivo principal:
# declarar o sitemap. As poucas regras abaixo têm cada uma sua razão.
#
# O que NÃO fica aqui, de propósito:
#
# - Caminhos internos. robots.txt é público: listar pasta sensível não protege
#   nada e entrega o mapa a quem varre o site. Quem protege essas pastas é o
#   "Require all denied" do .htaccess, que é bloqueio de verdade, no servidor.
#   Não é pedido de boa vontade ao robô.
#
# - Páginas que devem sair do índice. Disallow impede a LEITURA, e uma página
#   não lida é uma página cuja meta "noindex" o Google nunca enxerga: ela pode
#   continuar aparecendo na busca, só que sem descrição. Para tirar do índice,
#   o caminho é deixar rastrear e usar noindex na própria página, que é o que
#   os protótipos estáticos e o 404 fazem.
# =============================================================================

User-agent: *

# A saída de afiliado não é conteúdo: só conta o clique e redireciona.
# Bloquear aqui evita que robô inflando o contador estrague a única métrica que
# a cliente usa para saber qual página converte.
Disallow: /go/

Sitemap: https://wellira.example/sitemap.xml
